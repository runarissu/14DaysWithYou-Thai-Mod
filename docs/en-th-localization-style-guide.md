# English → Thai Localization Style Guide
## 14 Days With You (Ren'Py 8.5.2)

> มาตรฐานการแปลวิดีโอเกมจากภาษาอังกฤษเป็นภาษาไทย สำหรับใช้กับเกม *14 Days With You*
> อ้างอิงหลักการแปลเกมมืออาชีพ (IGDA Localization SIG, SEAMEO RELC, ราชบัณฑิตยสถาน)

## 1. หลักการพื้นฐาน (Core Principles)

| หลักการ | คำอธิบาย |
|---|---|
| **Meaning over Literal** | แปลความหมายและอารมณ์เป็นหลัก ไม่แปลคำต่อคำ (literal) จนประโยคแข็ง/ไม่เป็นธรรมชาติ |
| **Tone Preservation** | รักษาน้ำเสียง (tone) ของตัวละครให้ใกล้เคียงต้นฉบับ — ตลก ขี้เล่น จริงจัง หวาน ขู่ ฯลฯ |
| **Character Voice Consistency** | ตัวละครแต่ละตัวต้องมี "เสียง" ที่คงเส้นคงวา ดูตารางที่ 3 |
| **Context-Aware** | แปลตามบริบทของฉาก ไม่ใช่แปลแบบตัดตอน — คำเดียวอาจแปลต่างกันในฉากต่างกัน |
| **Idiomatic Thai** | ใช้ภาษาไทยเขียนมาตรฐานราชบัณฑิตยสถาน + ภาษาพูดธรรมชาติเมื่อตัวละครพูด |
| **No Over-Localization** | ชื่อเฉพาะ (proper nouns) ที่เป็นเอกลักษณ์ของเกม ควรคงไว้/ทับศัพท์ ไม่แปลเป็นไทย |

## 2. ระดับภาษา (Register / Formality)

เกมนี้มีหลายบริบท ต้องเลือกระดับภาษาให้เหมาะกับสถานการณ์:

| บริบท | ระดับภาษา | ตัวอย่าง |
|---|---|---|
| ผู้เล่นพูดกับเพื่อน (Moth, Violet, Jae) | **ภาษาพูดธรรมชาติ (Casual)** | "วันนี้ไปทำงานแล้วนะ บาย" |
| ผู้เล่นพูดกับคนรู้จักน้อย/คนทำงาน | **ภาษาสุภาพ (Polite Casual)** | "สวัสดีค่ะ ยินดีที่ได้รู้จัก" |
| ผู้เล่นพูดกับผู้ใหญ่/เจ้านาย | **ภายในเรื่อง (Formal)** | "ขอบคุณมากค่ะ" |
| ผู้เล่นคิดในใจ (narrator `n`) | **ภาษาเขียนบรรยาย (Narrative)** | ใช้ "ฉัน" เป็นสรรพนาม ไม่มีคำสุภาพ |
| ข่าว/ประกาศทาง TV | **ภาษาข่าว (News Formal)** | "เจ้าหน้าที่เชื่อว่า..." |
| ข้อความ chat/text | **ภาษาแชท (Internet Slang)** | ใช้คำย่อ ไม่มีวรรณยุกต์บางตัว ใส่ emoticon ได้ |
| UI / Menu | **ภาษาสุภาพกระชับ (UI Formal)** | "เริ่มเกม" "โหลดเกม" "ตัวเลือก" |

## 4. สรรพนาม (Pronouns) — ปัญหาใหญ่ที่สุด

### 4.1 ระบบ Pronoun แบบ Dynamic ของเกม

เกมนี้ใช้ระบบ pronoun แบบ dynamic ที่ผู้เล่นเลือกเอง (she / he / they / custom) แล้ว insert ลงใน dialog ผ่านตัวแปร:

| ตัวแปร | ค่าต้นฉบับ (English) | ใช้ในบริบท |
|---|---|---|
| `[they]` | she / he / they | Subjective — "they are safe" |
| `[them]` | her / him / them | Objective — "paying for them" |
| `[their]` | her / his / their | Possessive — "their life" |
| `[theirs]` | hers / his / theirs | Possessive pronoun |
| `[themself]` | herself / himself / themself | Reflexive |
| `[baby]` | girl / boy / person | "rat baby" |
| `[person]` | woman / man / person | "kind person" |
| `[partner]` | girlfriend / boyfriend / partner | Relationship |
| `[spouse]` | wife / husband / spouse | Marriage |
| `[gorgeous]` | pretty / gorgeous / handsome | Compliment |
| `[are]` | is / are | Verb agreement |

### 4.2 กลยุทธ์การแปล Pronoun เป็นไทย

ภาษาไทย **ไม่มี gendered pronoun** ในระดับคำเหมือนอังกฤษ และระบบสรรพนามไทยขึ้นกับ **ความสัมพันธ์ + เพศของผู้พูด/ผู้ฟัง** ไม่ใช่แค่เพศของประธาน จึงต้องใช้กลยุทธ์ดังนี้:

#### กลยุทธ์ A — แปลเป็นคำที่เป็นกลางเพศ (Recommended)

| ตัวแปร | ค่าไทย (ทุก pronoun) | หมายเหตุ |
|---|---|---|
| `[they]` | **เขา** | ใช้ "เขา" สำหรับทุก pronoun (เป็นกลางเพศในไทยสมัยใหม่) |
| `[them]` | **เขา** | เหมือนกัน |
| `[their]` | **ของเขา** | |
| `[theirs]` | **ของเขา** | |
| `[themself]` | **ตัวเอง** | |
| `[baby]` | **คน** | "rat baby" → "หนูน้อย" / "ตัวเล็ก" |
| `[person]` | **คน** | |
| `[partner]` | **คู่รัก** | ไม่ระบุเพศ |
| `[spouse]` | **คู่สมรส** | ไม่ระบุเพศ |
| `[gorgeous]` | **ดีตา** | หรือ "สวย" ถ้าอยากเน้น |
| `[are]` | **(ละไว้)** | ไทยไม่มี subject-verb agreement |

#### กลยุทธ์ B — Override ใน `refresh_pronouns()` (Recommended สำหรับเกมนี้)

เนื่องจากเกมใช้ `[they]` ในประโยค dynamic เยอะมาก (48 จุด) แนะนำ override ค่า pronoun ใน `refresh_pronouns()` ให้เป็นคำไทยตั้งแต่ต้น แล้วแปลประโยคใน `script.rpy` โดยใช้คำไทยเหล่านั้น:

```python
# ในไฟล์ mod: game/tl/thai/replace_pronouns.rpy
init python:
    def refresh_pronouns_thai():
        global they, them, their, theirs, themself
        global person, baby, partner, spouse, are, gorgeous
        # ภาษาไทยไม่มี gendered pronoun → ใช้คำเป็นกลางเพศทุกกรณี
        they = "เขา"
        them = "เขา"
        their = "ของเขา"
        theirs = "ของเขา"
        themself = "ตัวเอง"
        person = "คน"
        baby = "ตัวเล็ก"
        partner = "คู่รัก"
        spouse = "คู่สมรส"
        are = ""  # ไทยไม่มี verb agreement
        gorgeous = "ดีตา"
```

> ⚠️ ระวัง `[are]` ที่เป็น "" (ค่าว่าง) — ต้องเช็คประโยคที่ใช้ `[they] [are]` ว่าเมื่อละ `[are]` แล้วประโยคยังอ่านได้ ถ้าไม่ได้ต้องแปลประโยคนั้นเป็นกรณีพิเศษ

#### กลยุทธ์ C — แปลประโยคยากเป็นรายกรณี

ประโยคที่ pronoun เป็นประธานหลักและอ่านไม่ได้เมื่อแทน "เขา" ให้แปลใหม่ทั้งประโยค:

| ต้นฉบับ | แปลตรง (ไม่ดี) | แปลใหม่ (ดี) |
|---|---|---|
| `[they] [are] safe in my hands.` | "เขา ปลอดภัยในมือฉัน" | "เขาปลอดภัยอยู่ในมือฉัน" |
| `Where [are] [they]?` | "ที่ไหน เขา?" | "เขาอยู่ไหน?" |
| `paying for [them]` | "จ่ายให้ เขา" | "จ่ายให้เขา" |

## 5. การรักษา Tag และ Variable ของ Ren'Py

### 5.1 ห้ามแปล/แตะ Tag เหล่านี้เด็ดขาด

| Tag | ตัวอย่าง | ห้ามแปลเป็น |
|---|---|---|
| Text formatting | `{b}`, `{/b}`, `{i}`, `{/i}`, `{size=20}`, `{color=#fff}` | ❌ ห้ามลบ ห้ามแปล |
| Variable interpolation | `[player]`, `[ch_ren]`, `[they]`, `[affection_ren]` | ❌ ห้ามแปลชื่อตัวแปร |
| Special tags | `{w}`, `{p}`, `{nw}`, `{fast}`, `{clear}` | ❌ ห้ามลบ |
| Custom tags | `{renvoid=1}`, `{glitch=40.0}`, `{/renvoid}` | ❌ ห้ามแตะ |
| Escape | `{{`, `[[`, `\\` | ❌ ห้ามแปล |

### 5.2 ตัวอย่างการแปลที่ถูกต้อง

```renpy
# ต้นฉบับ
r "But don't worry, [they] [are] safe in my hands."

# แปลถูก ✅
r "แต่ไม่ต้องห่วงนะ [player] เขาปลอดภัยอยู่ในมือฉัน"

# แปลผิด ❌ (ลบ variable)
r "แต่ไม่ต้องห่วงนะ เขาปลอดภัยอยู่ในมือฉัน"

# แปลผิด ❌ (แปล variable name)
r "แต่ไม่ต้องห่วงนะ [พวกเขา] [คือ] ปลอดภัยในมือฉัน"
```

```renpy
# ต้นฉบับ
n "I wasn't about to let some morbid headline damper the start of my {b}cheery{/b} morning..."

# แปลถูก ✅
n "ฉันไม่มีทางยอมให้พาดหัวข่าวสยองมาทำลายบรรยากาศยามเช้าที่{b}ร่าเริง{/b}ของฉันหรอก..."
```

## 6. การทับศัพท์ vs การแปล (Transliteration vs Translation)

### 6.1 คงชื่อเดิม (Transliterate / Keep English)

| หมวด | ตัวอย่าง | เหตุผล |
|---|---|---|
| ชื่อตัวละคร | Ren, Moth, Violet, Elanor, Conan, Jae, Leon, Teo, Olivia, Kiara | เป็นเอกลักษณ์ของเกม |
| ชื่อสถานที่ | Corland Bay, Mount Corland, Lake Bluemoss | เป็น proper noun สมมติ |
| ชื่ออนิเมะในเกม | Attack on Giants (AoG), Haruko, Shizuka clan | parody อ้างอิงของจริง |
| ชื่อแบรนด์/ร้าน | "creston20" (code) | เป็นข้อมูลในเกม |
| คำศัพท์เทคนิค UI | Save, Load, Options, Start | คนเล่นเกมคุ้น |

### 6.2 แปลเป็นไทย

| หมวด | ตัวอย่าง |
|---|---|
| คำอุปมา/สแลง | "rat baby" → "หนูน้อย" / "ตัวเล็ก" |
| คำอารมณ์ | "ugh" → "อืด" / "เฮ้อ" |
| คำสแลงอินเทอร์เน็ต | "spoil it for me" → "สปอยล์ให้หน่อย" (ทับศัพท์ "สปอยล์") |
| ประโยค UI | "skip all the text" → "ข้ามข้อความทั้งหมด" |

### 6.3 ทับศัพท์ (Transliteration) เมื่อคุ้นกว่า

| อังกฤษ | ทับศัพท์ | แปลไทย |
|---|---|---|
| meme | มีม | ❌ ภาพตลก |
| spoiler | สปอยล์ | ❌ เปิดเผยเนื้อเรื่อง |
| streamer | สตรีมเมอร์ | ❌ ผู้กระจายเสียง |
| anime | อนิเมะ | ❌ การ์ตูนญี่ปุ่น |
| notification | การแจ้งเตือน | ✅ ใช้ไทยได้ |
| croissant | ครัวซองต์ | ✅ ทับศัพท์ |

## 7. วรรคตอนและเครื่องหมาย (Punctuation)

| เครื่องหมาย | กฎ |
|---|---|
| **จุด (.)** | ใช้แบบไทย — จบประโยคใช้เว้นวรรค ไม่ใช้ . |
| **จุลภาค (,)** | ใช้ในการแจกแจง ไม่ใช้ในตัวเลข (ใช้ช่องว่าง) |
| **อัศวจักร (!)** | ใช้ตามประโยคอุทาน |
| **เครื่องหมายคำถาม (?)** | ใช้ตามประโยคคำถาม |
| **อัญประกาศ ("...")** | ใช้ตามต้นฉบับ — เกมใช้ `"` ครอบ speech |
| **ขีดกลาง (—)** | ใช้ตามต้นฉบับสำหรับ interruption |
| **จุดไข่ปลา (...)** | ใช้ตามต้นฉบับสำหรับ hesitation |
| **เครื่องหมายทับ (/)** | ใช้ใน tag เท่านั้น ไม่ใช้ในข้อความ |
| **วรรณยุกต์** | ใส่ครบทุกตัว — ่ ้ ๊ ๋ ั ี ื ็ ฯ |
| **การเว้นวรรค** | เว้นวรรคระหว่างคำ 1 ช่อง ไม่เว้นหน้าวรรณยุกต์/ไม้ยุกต์ |

### ข้อควรระวังพิเศษ

- ภาษาไทย **ไม่ใช้จุดตอนประโยค** เหมือนอังกฤษ — ใช้การเว้นวรรคแทน
- แต่ในเกม Ren'Py ถ้าต้นฉบับมี `.` ท้ายประโยค ให้ **คงไว้** เพราะ engine ใช้ตรวจจับ end-of-line ในบางกรณี
- ห้ามลบ `\n` ในข้อความ — ใช้สำหรับ line break

## 8. ความยาวข้อความ (Text Length)

| ภาษา | อัตราส่วนเฉลี่ย |
|---|---|
| English → Thai | 1.0 – 1.3 เท่า (Thai มักสั้นกว่าหรือเท่ากับ English) |

### กฎเกณฑ์

- ถ้าข้อความไทยยาวกว่าอังกฤษมาก → พิจารณาย่อให้กระชับ รักษาความหมาย
- ระวังกล่อง dialog ที่จำกัดความยาว — ตรวจสอบในเกมจริง
- ประโยค UI ต้องสั้น เพราะปุ่มมีพื้นที่จำกัด

## 10. การแปล Narrator (`n`) — ผู้เล่นคิดในใจ

### หลักการ

- ใช้สรรพนาม **"ฉัน"** เสมอ (ผู้เล่น = ตัวเอก)
- ใช้ **ภาษาเขียนบรรยาย** (narrative prose) ไม่ใช่ภาษาพูด
- ไม่ต้องมีคำสุภาพ (ครับ/ค่ะ) — เป็น inner monologue
- รักษา tense แบบ narrative past ให้เป็นอดีต/ปัจจุบันตามธรรมชาติของไทย (ไทยไม่มี tense ชัด ใช้คำว่า "แล้ว/เคย/กำลัง" บอก)

### ตัวอย่าง

```renpy
# ต้นฉบับ
n "I wasn't about to let some morbid headline damper the start of my cheerful morning..."

# แปล ✅
n "ฉันไม่มีทางยอมให้พาดหัวข่าวสยองมาทำลายบรรยากาศยามเช้าที่ร่าเริงของฉันหรอก..."
```

```renpy
# ต้นฉบับ
n "There was even this adorable little bakery along the way that served the best shortcakes and croissants known to mankind..."

# แปล ✅
n "ยังมีร้านเบเกอรี่น้อยน่ารักอยู่ระหว่างทางที่ขายชอร์ตเค้กและครัวซองต์อร่อยที่สุดในโลกเลยก็ว่า..."
```

## 11. การแปล Chat / Text Message

### หลักการ

- ใช้ **ภาษาแชท** — สั้น ไม่เป็นทางการ ใส่ emoticon ได้
- ทับศัพท์คำอินเทอร์เน็ต (spoil, meme, btw, lol)
- ไม่ต้องมีวรรณยุกต์ครบถ้วน — ภาษาแชทจริงๆ ก็พิมพ์ไม่ครบ
- คง emoticon ของต้นฉบับ (^^, >.<, :'(, -.-;)

### ตัวอย่าง

```renpy
# ต้นฉบับ
mt "btwww! did u see the latest AoG ep?? i heard Haruko got an outfit change!!!!"

# แปล ✅
mt "อ่ะว่า! เห็นตอนล่าสุดของ AoG ป่ะ?? ได้ข่าวว่า Haruko เปลี่ยนชุดใหม่!!!!"

# ต้นฉบับ
mt "spoil it for me. did he really change his hairstyle as well? or was it really just his sorcerer outfit?"

# แปล ✅
mt "สปอยล์ให้หน่อย เค้าเปลี่ยนทรงผมด้วยป่ะ? หรือแค่ชุดจอมเวทเฉยๆ?"
```

## 12. การแปล Choice / Menu Options

### หลักการ

- สั้น ชัด เป็นตัวเลือกที่ผู้เล่น "พูด/ทำ"
- ใช้ภาษาพูดธรรมชาติ
- คง tag `[rh_o]...[rh_c]` (เป็น special choice style ของเกม)

### ตัวอย่าง

```renpy
# ต้นฉบับ
menu:
    "Say \"Thank you!\"":
        ...
    "Send back another sticker":
        ...
    "[rh_o]Reply later[rh_c]":
        ...
    "Send a meme with zero context":
        ...

# แปล ✅
menu:
    "พูดว่า \"ขอบคุณนะ!\"":
        ...
    "ส่งสติ๊กเกอร์ตอบกลับ":
        ...
    "[rh_o]ตอบทีหลัง[rh_c]":
        ...
    "ส่งมีมโดยไม่บอกบริบท":
        ...
```

## 13. การแปล Glitch / Error / Special Text

### หลักการ

- ความผิดปกติ (glitch, binary, error) — **คงไว้ทั้งหมด** ไม่แปล
- เป็นเอกลักษณ์ของเกม แปลจะทำลายบรรยากาศ
- คง tag `{glitch=...}`, `{color=#a30b11}`, `{renvoid=...}` ไว้ทั้งหมด

### ตัวอย่าง

```renpy
# ต้นฉบับ — ไม่แปล
n "{glitch=40.0}{color=#a30b11}ERR01101000 01101001{i}01101000 ...{/i}{/color}{/glitch}"

# ✅ คงไว้ทั้งหมด
```

## 15. Quality Assurance Checklist

ก่อนส่งมอบ translation ตรวจสอบ:

- [ ] ทุก tag `{...}` ครบถ้วน ไม่หาย ไม่เพิ่ม
- [ ] ทุก variable `[...]` ครบถ้วน ไม่แปลชื่อ
- [ ] สรรพนามตัวละครคงเส้นคงวา (Ren=ฉัน, Conan=ผม, ฯลฯ)
- [ ] วรรณยุกต์ครบถ้วน
- [ ] ไม่มีคำภาษาอังกฤษตกค้าง (ยกเว้นทับศัพท์ที่ตกลงกัน)
- [ ] ความยาวประโยคเหมาะกับกล่อง dialog
- [ ] บริบทตรงกับฉาก
- [ ] น้ำเสียงตรงกับตัวละคร
- [ ] ทดสอบในเกมจริง — ไม่มี error จาก tag ผิด
- [ ] ทดสอบเปลี่ยน pronoun ทุกแบบ (she/he/they/custom) — ประโยคยังอ่านได้

## 16. ข้อยกเว้นเฉพาะของเกมนี้

1. **Pronoun dynamic** — ใช้กลยุทธ์ B (override ใน `refresh_pronouns()`) เป็นหลัก
2. **Glitch text** — ไม่แปล คงไว้ทั้งหมด
3. **Chat message** — ใช้ภาษาแชท ทับศัพท์คำอินเทอร์เน็ต
4. **Narrator** — ใช้ "ฉัน" ภาษาบรรยาย
5. **Character name** — คงชื่อ English ทั้งหมด
6. **UI text** — แปลเป็นไทย ยกเว้นชื่อ key บนแป้นพิมพ์
7. **`[are]`** — override เป็น "" (ค่าว่าง) แล้วตรวจประโยค `[they] [are]` ทุกจุด

7. ทดสอบเปลี่ยน pronoun ทุกแบบ
8. บรรจุ mod เป็น `.rpa`
